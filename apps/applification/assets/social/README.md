# Social preview fonts

These static TrueType fonts match the site's Newsreader and Geist families.
They are bundled locally so Open Graph images can be generated at build time
without fetching fonts from another service.

- Geist Regular, weight 400, from Google Fonts.
- Newsreader Regular, weight 400 and optical size 60, from Google Fonts.

Both use the SIL Open Font License. The corresponding licences are included here.

Font source: <https://fonts.googleapis.com/css2?family=Newsreader:opsz,wght@60,400&family=Geist:wght@400&display=swap>
